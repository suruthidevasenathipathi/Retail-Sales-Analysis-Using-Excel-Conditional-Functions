🛠️ Tools and Functions Used

Tool: Microsoft Excel / Excel Online

Functions practiced:

SUMIF() – Calculates the total sales amount for a specific product.

AVERAGEIF() – Calculates average profit for a selected region.

SUMIFS() – Calculates total sales using multiple criteria.

AVERAGEIFS() – Calculates average profit using multiple criteria.

MAXIFS() – Identifies the highest sales amount under specified conditions.

MINIFS() – Identifies the lowest profit under specified conditions.

These functions were used to perform conditional calculations across products, categories, and regions.
